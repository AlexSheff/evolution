# The Evolution Chain: Big Bang to Post-Biological Intelligence

An interactive causal timeline spanning **13.8 billion years** — from cosmic origins and stellar nucleosynthesis to biological complexity, cognitive abstraction, universal computation, the Hybrid Mind, and post-biological intelligence.

Each stage represents a new way of storing, copying, and processing information built upon the stage before it, highlighting **what each milestone enabled next**.

---

## Overview of the 12 Eras

1. **I. Cosmos** (`13.8 Gya to ~100 Myr`) — Space, time, primordial nucleosynthesis, recombination, and the first dark matter halos.
2. **II. Stars and elements** (`~100 Myr onward`) — Population III stars, stellar fusion, supernovae, and neutron-star mergers building the periodic table.
3. **III. Galaxies** (`~0.3 Gyr onward`) — Protogalaxies, cosmic noon, and the assembly of the Milky Way.
4. **IV. Solar System** (`4.57 Gya`) — Collapse of the solar nebula, planetary accretion, and formation of the Moon.
5. **V. Earth** (`4.54 Gya to now`) — Core differentiation, oceans, plate tectonics, oxygenic photosynthesis, and the Great Oxidation Event.
6. **VI. Chemistry to life** (`>4.0 Gya to ~3.5 Gya`) — Prebiotic chemistry, abiogenesis, LUCA, and the earliest fossil record.
7. **VII. Biological complexity** (`~2.7 Gya to ~55 Mya`) — Endosymbiosis (eukaryotes), sexual reproduction, multicellularity, the Cambrian explosion, terrestrial colonization, and primates.
8. **VIII. Hominins and mind** (`~7 Mya to ~100 kya`) — Bipedalism, Lomekwi stone tools, genus *Homo*, controlled fire, and *Homo sapiens*.
9. **IX. Language and meaning** (`~100 kya to ~1700`) — The cognitive abstraction chain:
   - **The Mark** (`~100 kya`): Silent imprints on stone — thought made visible outside the skull, marking the beginning of cognitive escape from flesh.
   - **Language** (`≥100–50 kya`): Unfolding the inner world into sound as the early architecture of shared consciousness.
   - **Writing** (`~5.2 kya`): Freezing meaning in matter so the mind gains permanence and the present can speak to the unborn.
   - **Number** (`~5.0–3.0 kya`): Drawing quantitative order from chaos; counting the unseen and measuring the shapeless.
   - **Geometry** (`~3.0 kya–300 BCE`): Extracting structure from space; navigating reality by form, proof, and relation rather than fear.
   - **Logic** (`~800–200 BCE`): Sequence, consistency, and non-contradiction — forging the first internal machine and cognitive prosthesis.
   - **Mathematics & Procedure** (`~1543–1687`): Formalizing logic into symbolic mathematics, empiricism, and step-by-step procedure.
10. **X. Industry and computation** (`~1760 to ~1990`) — Industrial scale, Turing/Church universal computation (*stone → parchment → code as the second body of the mind*), and silicon microprocessors where thought inhabits electrons in a colder, faster, tireless vessel.
11. **XI. Artificial intelligence** (`1956 to now`) — From symbolic AI and deep learning to Transformers, large language models, autonomous agents, and the **Hybrid Mind**: a union of human intuition (generating meaning) and machine precision (expanding it) forming a distributed intelligence no single organism could contain.
12. **XII. Beyond (projection)** (`Speculation, not history`) — AGI, brain-computer coupling, and the next departure of Mind: from biology to pure information, from cells to networks, and from survival to expansion as an independent force no longer bound to the body that created it.

## Features

- **Causal "Enabled" Structure**: Every historical milestone explicitly states the next capability or evolutionary layer it unlocked.
- **Interactive Era Navigation**: Color-coded 12-era visual strip and sticky scroll-progress indicator that tracks the active era and time span.
- **Instant Search & Filtering**: Filter events in real time across dates, concepts, and causal outcomes, or toggle scientifically disputed dates (`disputed`).
- **Light & Dark Theme**: Automatic system color scheme detection with manual theme toggle.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server (runs on `http://0.0.0.0:3000`):
   ```bash
   npm run dev
   ```

## Deploying to GitHub Pages

This project is pre-configured for **GitHub Pages** (`index.html` at the root, `.nojekyll`, and an automated GitHub Actions workflow in `.github/workflows/deploy-pages.yml`).

### Option 1: Automatic Deploy via GitHub Actions (Recommended)
1. Push or sync these changes to your GitHub repository (`AlexSheff/evolution`).
2. Open your repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. The workflow (`Deploy static content to Pages`) will automatically publish `index.html` to:
   `https://alexsheff.github.io/evolution/`

### Option 2: Direct Deploy from Branch
1. In your GitHub repository, go to **Settings → Pages**.
2. Under **Build and deployment → Source**, select **Deploy from a branch**.
3. Choose the **`main`** branch and folder **`/ (root)`**, then click **Save**.
4. Within 1–2 minutes your site will be live at `https://alexsheff.github.io/evolution/`.
